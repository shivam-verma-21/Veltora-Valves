CONSTRUCTION OVERVIEW

Designed for Reliable Flow Direction Control

Swing check valves use a movable closure element that responds to the direction of fluid flow. During forward flow, the closure moves away from the seat; as flow falls or reverses, it returns toward the seat to help limit backflow.

The listed VELTORA options include a flanged valve with a bolted bonnet and a threaded screwed-type valve. Before installation, verify flow direction, allowable orientation, connection dimensions, closure characteristics, pressure-temperature limits and approved material selection.

SUPPORT & TECHNICAL INFORMATION

Frequently Asked Questions

Find answers to common questions about VELTORA Swing Check Valves, flanged bolted-bonnet and threaded screwed-type models, flow direction and technical selection.

01What is a Swing Check Valve?

A Swing Check Valve is an automatic non-return valve. Its movable closure responds to forward flow and returns toward the seat when flow reduces or reverses, helping to limit backflow. Actual performance depends on valve design and operating conditions.

02What is the flanged bolted-bonnet configuration?

The first listed product uses flanged end connections and a bolted bonnet arrangement. Confirm flange facing, drilling, cover details and dimensions against the approved product drawing.

03What is a threaded screwed-type Swing Check Valve?

The second listed product uses a screwed-end connection for compatible threaded piping. Confirm the required NPT, BSP or BSPT thread form, model size and pressure limits before selection.

04Which body, trim and seat materials are available?

The supplied Check Valve range lists carbon steel, stainless steel, forged carbon steel, forged stainless steel, duplex and super duplex options. Seat and sealing options include PTFE, RPTFE, PEEK, graphite and Stellite hard-faced seats. Exact combinations depend on the selected model.

05What pressure ratings and sizes are listed?

The supplied Check Valve range lists ANSI Class 150 to 2500 and sizes from ½ inch (DN15) to 48 inches (DN1200). These are category-level ranges; confirm the exact rating and size combination for the selected swing model.

06Which standards and tests may apply?

The supplied range lists API 594, API 6D where applicable, BS 1868, ASME B16.34, MSS SP-71 and MSS SP-80 for threaded types. Testing standards include API 598, API 6D for applicable models, ISO 5208 and MSS SP-61. Confirm the applicable standards for the selected design.

07How can I request pricing and technical specifications?

Share the valve connection, size, pressure class, process medium, operating temperature, flow direction and installation position with VELTORA. The team can discuss the available model configuration, technical documentation and quotation.
