04 / FREQUENTLY ASKED QUESTIONS

Industrial Check Valve FAQs

Answers to common questions about VELTORA VALVES PVT. LTD. check valve categories, materials and specifications.

Which check valve categories are listed?

The categories on this page are Stainless Steel Check Valves and Forged Steel Check Valves. Open the relevant category to view its product models.

Which materials are available for check valves?

The supplied material range includes carbon steel, stainless steel, forged carbon steel, forged stainless steel, duplex and super duplex stainless steel, Monel®, Inconel®, Hastelloy®, titanium, Alloy 20, nickel, bronze and aluminium bronze. Confirm the exact grade and availability for the selected valve.

Which design standards are mentioned?

The supplied information lists API 594, API 602 for forged check valves, API 603 for stainless steel check valves, ASME B16.34, API 602 — Forged Check Valves and MSS SP-71. Confirm the applicable standard for the specific model.

What pressure classes and sizes are listed?

The supplied range lists ANSI Class 150, 300, 600, 900, 1500 and 2500, and sizes from ½ inch (DN15) to 48 inches (DN1200). Larger sizes and customized configurations are subject to project specifications and confirmation.

Which end connections can I request?

Listed options are flanged ends (RF / RTJ), butt-weld ends, socket-weld ends, threaded ends (NPT / BSP / BSPT) and customized end connections. Confirm availability for the required valve design.

What testing and inspection options are listed?

The supplied information lists API 598, API 6D (applicable models), ISO 5208 and MSS SP-61. Inspection items include hydrostatic shell, seat leakage, back seat and hydrostatic closure tests, visual and dimensional inspection, material traceability, and PMI or NDT methods on request as applicable.

Can check valves be customized for project requirements?

The supplied information mentions customized materials, pressure classes, end connections and configurations. Share your technical requirements with VELTORA VALVES PVT. LTD. to confirm what can be provided for the specific application.

How can I request a quotation?

Contact VELTORA VALVES PVT. LTD. through the website enquiry page and share the valve category, size, pressure class, material, end connection, quantity and applicable project specifications.
